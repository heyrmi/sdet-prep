# Company-Wise SDET / QA Question Bank

> **932 real interview questions across 32 companies.** Verbal / scenario style — the kind an interviewer asks you to *reason through* (test strategy, automation design, system-quality, situational). No code to submit; the skill is structured, out-loud reasoning.

## How to use this

1. Pick your target company. 2. Work top-down by difficulty. 3. For each question, answer out loud in a structured way (clarify → approach → test design → trade-offs → edge cases → wrap-up), time-boxed to the suggested limit. 4. Cross-reference the [SDET guide](../SDET_INTERVIEW_QUESTIONS.md), [System Design course](../../sd/), and [framework](../../framework/) for the *how*.
